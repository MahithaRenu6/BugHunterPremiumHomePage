A premium frontend experience for BugHunter AI — designed to help developers discover, understand, and resolve code vulnerabilities.

## Tech Stack

- React
- Tailwind CSS
- CSS
- Framer Motion / GSAP

- Interactive vulnerability detection visuals
- Code analysis showcase
- Before / after vulnerability resolution

- Mobile-friendly UI
